## 🚀 Proyek unggulan

### [Tracking](https://github.com/Reverseflash45/Tracking) — satu aplikasi untuk seluruh hidup mahasiswa

Aplikasi Flutter yang menyatukan hal-hal yang biasanya tercecer di lima aplikasi berbeda:
akademik, kebugaran, nutrisi, keuangan, tidur, dan lari — dalam satu tempat.

| | Fitur |
|---|---|
| 🎓 | **Akademik** — impor KRS & KHS lewat OCR, jadwal kuliah dengan deteksi bentrok, tugas berulang, dan hitung IP otomatis |
| 💪 | **Latihan** — template workout, *progressive overload*, streak, dan penghitung repetisi **real-time lewat kamera** (ML Kit Pose Detection) |
| 🥗 | **Nutrisi** — catat makanan, pindai **barcode** produk, dan target kalori dari profil tubuh |
| 💸 | **Keuangan** — pencatatan transaksi plus **parser struk belanja** dari foto |
| 🏃 | **Lari** — pelacakan GPS dengan peta, jarak, dan pace |
| 📊 | **Wrapped** — rekap tahunan dari semua data yang terkumpul |
| 🔌 | **Offline-first** — cache lokal dan antrean tulis tertunda, tetap jalan tanpa sinyal |
| 🔔 | **Pengingat pintar** — notifikasi lokal yang sadar zona waktu |

**Dibangun dengan:** Flutter · Riverpod · go_router · Supabase (Auth, Postgres, Storage, Edge Functions) · Google ML Kit (pose, teks, barcode) · fl_chart · flutter_map
